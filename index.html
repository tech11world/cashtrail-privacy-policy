1. Introduction

CashTrail is a personal expense tracking and financial ledger application built with an offline-first architecture. This Privacy Policy discloses our practices concerning the collection, use, local processing, and retention of data when you use the CashTrail Android application.

Core Privacy Principle: CashTrail operates with a strict, complete financial air-gap. The application does not declare the android.permission.INTERNET permission in its Android Manifest, has no network communication libraries, and cannot transmit data over the internet. All processing and storage occur exclusively on your local device.

2. Permitted Use Category (Google Play SMS Policy)

CashTrail uses SMS permissions under Google Play’s permitted use category: SMS-based financial transaction management (Financial Services).

The core functionality of CashTrail requires access to financial transactional SMS messages to:

  • Automatically identify incoming bank, credit card, and UPI payment notifications.
  • Parse transaction attributes (amount, date, merchant/counterparty, debit/credit type).
  • Categorize spending and maintain a local personal ledger.
  • Provide spending insights and monthly summaries.

3. Permissions Requested & Data Access

CashTrail requests only the permissions strictly required for its core financial management features:

A. android.permission.READ_SMS (SMS Read Permission)

  • When it is used: Only when you explicitly initiate the “Import Past 30 Days” feature in the app.
  • What is accessed: The local device SMS inbox for messages received within the preceding 30 days.
  • What is ignored: Personal messages, conversations with individual contacts (numeric senders), and One-Time Passwords (OTPs) are strictly ignored and never parsed, recorded, or retained.

B. android.permission.RECEIVE_SMS (SMS Receive Permission)

  • When it is used: For real-time transaction detection when incoming bank alerts arrive.
  • What is accessed: Incoming SMS broadcast alerts matching institutional financial sender formats (such as standard Indian 6-character bank headers like VM-HDFCBK, AX-SBIINB, BZ-ICICIB) or senders explicitly verified by you.
  • User Control: Real-time detection can be toggled on or off at any time in the app’s Settings under “Automatic SMS Detection”.

C. android.permission.POST_NOTIFICATIONS (Notification Permission)

  • When it is used: On Android 13+ (API level 33+) to display local alerts when a new transaction is recorded or requires user review.
  • Lockscreen Privacy: Public lockscreen notifications carry zero financial metadata (displaying only “CashTrail: New transaction detected” or “CashTrail: New item needs review”). Amounts and merchant details are displayed only when your device is unlocked.

4. How SMS Data Is Processed and Stored

On-Device In-Memory Processing

All SMS parsing and regular expression matching occur entirely on-device in memory. CashTrail extracts only structured transaction attributes:

  • Transaction amount
  • Transaction type (Debit or Credit)
  • Transaction timestamp
  • Extracted merchant / counterparty name
  • Cryptographic SHA-256 fingerprint (generated from transaction fields for deduplication)

Raw SMS Discarded (Data Minimization)

  • The original raw text body of the SMS is discarded immediately after in-memory parsing.
  • Raw SMS messages are never stored in the application's persistent database.

Local Database Storage

Extracted transaction records and categorization rules are persisted locally on your device using an Android Room SQLite database (spendlens.db).

  • Storage Location & Encryption: The database is stored within the application's private internal storage directory (/data/data/com.spendlens/databases/). It is protected by standard Android operating system sandbox permissions and hardware-backed device encryption (File-Based Encryption / FBE) provided by your Android device. It is not encrypted with custom application-level database encryption (such as SQLCipher).
  • No Cloud Backups: Android system backups are explicitly disabled (android:allowBackup="false" in the Manifest) to prevent local transaction databases from being uploaded to Google Drive or external cloud backup providers.

5. Third-Party Sharing and Data Transmission

  • Zero Data Transmission: CashTrail does NOT transmit, upload, or export your SMS messages, transaction data, or personal details to any remote server, cloud service, or external entity.
  • No Third-Party SDKs: CashTrail includes zero third-party advertising SDKs, zero analytics tracking tools (e.g., Firebase, Google Analytics, Mixpanel, Sentry), and zero tracking pixels.
  • No Third-Party Sharing: We do not sell, rent, monetize, or share your data with advertisers, financial institutions, data brokers, or any third parties.

6. User Control, Retention, and Data Deletion

  • Transaction Deletion: You can delete any individual transaction or review item directly within the app at any time.
  • Merchant Rules Deletion: You can view, modify, or delete custom merchant categorization rules at any time in Settings.
  • Permission Revocation: You can revoke READ_SMS, RECEIVE_SMS, or POST_NOTIFICATIONS permissions at any time via Android System Settings (Settings > Apps > CashTrail > Permissions).
  • Complete Data Erasure:
    • Clearing application data via Android System Settings (Settings > Apps > CashTrail > Storage > Clear Data) immediately and permanently deletes the local database and all associated preferences.
    • Uninstalling CashTrail permanently deletes the entire local database and all transaction records from your device.

7. Security Safeguards

  • No Network Permission: The absence of android.permission.INTERNET guarantees at the OS level that network sockets cannot be opened by CashTrail.
  • Cleartext Traffic Disabled: Cleartext (HTTP) traffic is forbidden app-wide via Android Network Security Configuration as defense in depth.
  • No External Content Providers: CashTrail does not expose any database ContentProvider to other applications on the device.

8. Children's Privacy

CashTrail is a financial utility not directed to children under the age of 13. Because no data is collected or transmitted, we do not knowingly collect personal information from children.
